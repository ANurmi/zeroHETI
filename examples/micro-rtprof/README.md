# Real-time profiling (micro)benchmark [micro-rtprof]

## Quickstart

Compile the Verilator DUT model once (per design) with

```sh
make verilate INTC={CLIC, EDFIC}
```

from the repository root. Run the benchmark by navigating to `examples/micro-rtprof` and running

```sh
LOAD_FACTOR=<Y> RUNTIME_MS=<X> [DEBUG=1] cargo run --release -Frtl-tb,intc-{clic,edfic}
```

### Variables, flags
- `LOAD_FACTOR`: Theoretical CPU utilization factor, does not account for interrupt overheads, i.e,, context switching.

- `RUNTIME_MS`: Runtime of the actual measured benchmark workload in milliseconds.

- `DEBUG=1`: Waveforms are not generated by default, but can be generated by adding this flag with this exact format. Omit completely if not needed. NOTE: Tracing waveforms will significantly low down simulation speed.

### Waveform
If you generated a waveform for this benchmark, the task set can be visualized by running from the repository root: 
``` sh
surfer build/verilator_build/waveform.fst -s micro-rtprof.surf.ron
```

NOTE: [Surfer 0.7.0](https://gitlab.com/surfer-project/surfer/-/releases) or higher is required.

## VS Code

For rust-analyzer on VS Code, you'll need this in settings.json:

```json
"rust-analyzer.server.extraEnv": {
    "RUNTIME_MS": 10,
    "LOAD_FACTOR": 50,
},
```
